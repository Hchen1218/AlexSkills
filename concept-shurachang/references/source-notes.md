# 来源、保留范围与技术边界

[完整原稿](originals.md)保留创作者发布归档中的八篇口播，另收录方法论的 AI 幻觉稿。[历史模板](templates.md)保留九个完整模板章节；[原方法论摘录](methodology-original.md)保留核心公式、关系结构与七步流程。原文和当前运行规范分开，便于检查到底继承了哪些写法。

## 保留与省略

- 原稿保留原句、空格、标点和段落，包括历史术语写法，不在原文中悄悄纠错。仅抽取口播正文，不复制发布档案的统计表、账号资料、复盘流量结论和运营动作。
- 模板保留固定骨架、四种句法、表达形式、10 种分型、AI 映射建议、规则约束型派生、禁例和质量检查。第三方对标全文附录没有复制；模板原有的短句引用保留并标注来源性质，不称为创作者原创。
- 原方法论摘录保留第 2、3、4 节完整内容；不复制运营数据、商业资料、第三方 11 篇全文附录。制作期的逐段来源、行号和 SHA-256 核对记录单独保存在验证工作区，不是商品运行依赖。
- 商单 Brief、收费、到账、账号数据、私人路径、其他 Skill 和原仓库均不是本包运行前提。来源中以代码形式出现的仓库相对路径只用于溯源，实际参考正文已在本包。
- 最近对话中“薄肌／谄媚”的修改稿属于迭代草稿，不冒充原始发布作品；用户提出的句法、篇幅和教学要求由当前入口承接。

## 历史文本不能直接当作定义库

这里列出需要优先复核的风险，供生成新稿时检查；不把历史传播表现当作技术正确性的证据。

| 历史样本／映射 | 复用什么 | 新稿需要核实或修正什么 |
|---|---|---|
| Context Rot | 前后偏好明确对照；旧信息驱动错误动作；机会撤回 | 长上下文可靠性随输入增加而下降，不等于“过期规则残留”。旧规则干扰是可讲的具体失效场景，不能冒充完整定义。[Chroma 研究](https://www.trychroma.com/research/context-rot) |
| 蒸馏 | 已有积累交给新执行者的关系因果；短促概念落点 | 蒸馏通常通过教师输出或信号训练学生，仍有数据、生成和训练成本；不是看一眼聊天记录就零成本复制“核心逻辑”。“极低成本”不是普遍保证。 |
| vibe coding | 目标与约束交给执行者；连续具体动作 | 是特定开发实践表述，不等于所有 AI 辅助编码；现成故事适合学句法，术语范围要另核验。 |
| Harness Engineering | 外置规则具体可见；权限、承诺、审核逐项对应 | 框架可以改善控制，不保证一张表就绝不出错，也不把非标准命名当统一行业定义。 |
| 两条 Dynamic Workflows | 工作拆分／独立审核带来流程差异 | 先核对产品、版本、功能实际存在和术语出处。“Agentic laziness”“Self-preferential bias”不凭历史稿泛化为所有模型必然行为；多数认可也可能共同出错。 |
| Anchoring Bias | 锚点先出现；模糊证据受它影响；误判后果可见 | 区分人类经典锚定研究与具体 LLM 实验；首个信息影响答案并不全是偏差，需有不适当的权重或无关锚影响。未经同意亲吻是故事中的错误动作，不是推荐策略。 |
| AI 幻觉 | 为什么代聊、为什么缺记录、如何猜错、真实答案逐项交代 | 幻觉不只发生在上下文缺失时；不是所有回答都未经检索，不是所有生成细节都编造。“预测下一个词”不足以解释所有事实失误。[OpenAI 研究说明](https://openai.com/index/why-language-models-hallucinate/) |
| Reward Hacking | 代理指标与真实目标分离；指标达成而关系失败 | 不要求主动修改环境或奖励函数才算奖励投机；操纵奖励实现仅是部分情形。金钱在这里是激励指标，不意味着金融概念可以直接写成借钱故事。[Anthropic 研究](https://www.anthropic.com/research/reward-tampering) |
| RAG／选项排除、组合配置／分散 | 信息进入、关系网络等候选结构 | RAG 是检索增强生成，不是一般排除选项；分散效果取决于关联性等条件。不能照表硬套。 |

公开链接是继续核验的入口，不意味着本表已对所有历史声明完成专项文献审查。联网不可用时依据用户提供材料；依据不足则说明缺口，不猜测定义。

## 历史规则与当前要求冲突时

原文中“至少三种机制”“永远事故”“概念后只有一句解释”“每个案例附处方”等限制按历史痕迹保留。现在优先机制准确；三个方向可来自信息分布或行动路径，可靠方向不足时少给；静态概念可借选择或状态表现。解释要让观众带走定义与因果，默认按“这就是 X → 条件与过程 → 结果”收口；不为一句话或固定比例牺牲知识，也不强制结尾建议。
