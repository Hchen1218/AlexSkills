# 方法与判断

## 从机制到故事

先写一句“在什么条件下，哪个变量如何变化，产生什么结果”。它可以是因果过程，也可以是受约束的选择关系。比喻只保留需要讲清的结构，不追求把整个学科塞进一段关系事故。

## 先确认发生了真正的映射

完整路径是“专业机制 → 去掉学科名词的结构 → 两性关系中的对应结构”，呈现顺序才是故事先、概念后。

- 不合格：前任催还钱、现任帮周转，用这段故事解释流动性。催还、资金到期和周转仍是金融机制，恋爱只是背景。
- 同样不合格：把“钱”机械改称“爱”、把“借贷”改称“借感情”，却说不清具体的人会做什么。
- 合格方向：把看似独立却共享风险来源的结构，映射成几段暧昧关系通过共同朋友圈互相影响。先让人物动作和传播路径成立，再讨论分散与相关性的概念。

候选阶段就问：移除暧昧人物标签后，它是否仍是原学科的直接例题？若是，重新映射。再反向问：不提任何专业概念，关系里的承诺、行动和后果是否真实可理解？若否，不靠术语替人物补逻辑。

用户指定的概念找不到可靠映射时说明困难，不用贴皮故事凑数；用户只指定领域时，优先换成在该领域内更容易保持同构的概念。

建立五层对应，缺少的层可说明不适用，不编造角色：

| 层 | 专业侧要确定的事 | 故事侧要演出的事 |
|---|---|---|
| 角色 | 谁做决定、谁提供信息、谁执行 | 你、对象、朋友、代办者；必要角色才出现 |
| 目标 | 要完成什么，或在什么约束下选择 | 约会、确认关系、兑现承诺、协调安排 |
| 信息 | 什么可见、缺失、过期或被误判 | 聊天记录、已知安排、听来的话、公开表态 |
| 动作 | 哪个操作改变了后续状态 | 回复、转交、选择、修改、拒绝、核实 |
| 结果 | 变量最终如何改变，是否符合目标 | 机会撤回、计划落空、误会扩大，或协调恢复 |

先补结构细节，再加风格：删除某个细节会让行动没理由，它是结构细节；删除后只改变口吻，它是风格细节。每条选一到两个风格点即可。

## 故事方向库

以下是寻找同构关系的入口，不是专业概念的固定分类。先检查结构，再采用；没有合适项可设计新结构。

| 关系结构 | 重点检查 |
|---|---|
| 过去规则影响当前关系 | 旧信息为何仍可见？当前要求有什么不同？ |
| 最先听到的数值牵引估计 | 后续判断是否仍围绕初始值，且调整不足？ |
| 代理人用局部线索补空白 | 为什么委托、缺了什么、根据什么补、哪里能核真？ |
| 表面指标与真实目标分离 | 奖励绑定什么，执行者如何提高指标却损害目标？ |
| 多人消息或行动互相影响 | 连通关系和传播路径是否真实存在于故事？ |
| 有限时间中的互斥选择 | 备选是否实际可行，人物偏好和约束是否清楚？ |
| 观察偏离后调整行动 | 反馈是否回到被调节的变量，而非单纯惩罚？ |
| 私下态度与公开表现错位 | 是谁误判谁，是否有证据揭示私下与公开不同？ |

## 张力与口播

事故型常用推进：明确暧昧信号 → 机会临近 → 具体信息／操作介入 → 错误动作 → 机会骤然撤回 → 概念揭晓。不要花第一段介绍普通约会背景，第一句就让观众感到“关系要往前一步了”。

强暧昧来自具体行动：靠近后等你回应、约会结束仍邀你留下、只对你开放的邀请、突然变得明确的称呼；撤回也应可见，如拉开距离、收回邀请、转身离开。选与机制同构的信号，不把这些细节当成必用台词库。

强度检查：去掉“小美／顶美”，观众是否仍能感到这次机会很想得到？错误之后究竟失去了什么？若只是在核对时间地点，补清这次见面的关系意义。用成年人之间的自愿暧昧与反差即可，不需要露骨行为、胁迫或将拒绝解释成邀请。

选择型可写“两个机会不能兼得”；协调型可写“偏离后调整并恢复”。这些仍可有张力，不必强加坏人或失败。

默认从“你”进入具体处境，用连续句段推进。概念先由故事演出，再用足够但紧凑的解释讲清定义、对应和一个可带走的判断；不把“一句定义”或固定故事占比当成硬限制。关键术语揭晓前，观众应已知道发生了什么。

用户要求对齐对标长度时，读取指定或结构最接近的实际口播，以相同口径计算字数，不用整份方法论长度或含编辑批注的字符数替代。报告原稿和新稿数字；新稿为补足知识而略长时明确差距。没有原文就说明不能精确比较。压缩优先去掉重复邀请、无关人物和重复反转，保留机制信息及专业解释。

候选阶段不用先写三篇完整稿。短段落或紧凑表格即可，避免让用户在长文中找差异。默认给推荐项，用户选定后再打磨。

## 跨领域核验

- AI：区分观测现象和已证实原因；对人类的研究不能直接证明某模型存在同样偏差。
- 经济学：先交代资源约束、备选和偏好；不要把模型结论写成对所有关系的事实判断。
- 生物学：保留系统、时间尺度与作用方向；人物意图不能替代真实生理或进化机制。
- 社会学：区分个体心理和群体结构，研究样本的结论不能无条件推广到所有男女。
- 有争议、定义不一或需要公式的概念：选明解释范围。故事只能作引子时如实说明，不声称一段故事覆盖完整理论。

## 成稿判断

按优先级检查：

1. **概念正确**：条件、变量、作用方向有依据；没有混用近邻概念。
2. **故事完整**：行动有理由，信息边界明确，结果由前面的结构产生。
3. **映射可逆**：专业侧的重要条件在故事中有对应，故事没有引入会推翻概念的关键条件。
4. **口述自然**：连续动作比解释多；术语只承担必要工作；删冗余后仍能讲清。
5. **风格可辨**：两性关系张力明确，保留用户选择；不靠羞辱、露骨细节或绝对化性别判断。

6. **知识获得感**：只听口播的观众能否说出概念描述什么，以及一个新的判断或区别？如果只能记住故事和术语名，解释还不够；核对卡不能代替这段教学。

公开核对卡只呈现必要结果。分清“写作判断”“研究结论”“虚构情节”，不要输出未经证据支持的成功预测。
