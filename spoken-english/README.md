# Spoken English

成人持续口语练习：基础开口／复杂表达两路线，约15分钟可中断。不是考试评级或发音评分工具。研究边界见 [依据表](references/evidence.md)。

## 安装与数据

需要 Python 3.10+。将整个 `spoken-english` 文件夹放入个人技能目录；不要只复制 SKILL.md。创建专用环境并安装固定依赖：

```sh
python3 -m venv /absolute/path/to/spoken-english-venv
/absolute/path/to/spoken-english-venv/bin/pip install -r /absolute/path/to/spoken-english/requirements.txt
```

每次调用使用这个环境的 Python，或把其绝对路径写入 `SPOKEN_ENGLISH_PYTHON`／`~/.config/spoken-english/config.json` 的 `python_path`，再用不依赖当前目录的 `scripts/run.py`。先指定永久绝对数据目录：`--data-root /absolute/private/data`，或环境变量 `SPOKEN_ENGLISH_DATA_ROOT`，或同一配置文件中的 `data_root`。不会根据当前目录选数据目录；无配置不偷偷创建档案。安装目录、工作树、测试目录不应是持久数据根。

本机已批准默认数据位置为 `/Users/cecilialiu/Documents/Codex/Skills/.artifacts/spoken-english/`；这只是本机配置，分享给别人时由对方选目录。别把个人数据库、手机包、记录、备份发进分享包。

从“用 spoken-english 陪我练口语”开始。首次建立学习者身份和目标，后续读取摘要及未完成会话。对话观察只用于路线建议。操作脚本请先读 [引擎协议](references/protocol.md) 并运行 `scripts/practice.py --help`，不能杜撰字段。

表达卡保存表达、含义、沟通功能、适用情境、个人例句、来源和提示；没有观察到的信息明确写 `unknown`。会话快照保存方法与调度版本。运行本地应用、手机导入或 `report` 后，私有数据目录会更新 `summary-学习者ID.md`，分别展示练过、独立想起、延迟回忆和新情境运用，并给出下一阶段重点。

## 手机完整试用

1. 电脑建立学习者和少量真实卡片，运行 `export-mobile --learner ID --out /absolute/private/export --at 带时区ISO时间`。数据根参数放子命令前。先检查输出不含你不愿上传的原话。
2. 手机上新建ChatGPT聊天或项目，复制／上传导出的独立教学说明、进度包和记录模板。说：“按教学说明，一次一个任务，先开始到期回忆。”无需加载仓库或运行脚本。
3. 开语音练习，随时要求暂停并生成记录卡。只有真正能分析声音时才做声音反馈；若助手只有转写，明确只评文本。检查记录保留失败、提示和未完成。
4. 在同聊继续第二次练习；换聊时携带原进度包和全部未同步记录。手机暂用旧队列和近期失败项，不计算FSRS。
5. 回电脑，将一次或多次记录的固定JSON区保存文件或粘贴stdin导入。先修正格式或模糊日期；相同ID异内容冲突须查清后重新整批导入，不能静默选“成功”。新增卡映射随导入保留。
6. 导入后看个人报告、事件数和新到期日期；重复导入应不增加事件。再次导出新包，手机改用新包。旧包保留档案但不能覆盖本地历史。

[OpenAI 官方项目说明](https://learn.chatgpt.com/zh-Hans/docs/projects?surface=app)支持上传来源和共享指令，并说明ChatGPT项目不能直接访问电脑文件夹。具体手机账号、语音模式与文件上下文组合仍需实机验收；本项目没有声称已经验证这些组合。

## 七天观察（不是疗效试验）

| 日 | 练什么 | 看什么 |
|---|---|---|
| 1 | 小问答选路线、一个真实场景 | 单个意思、提示依赖；记初始样本 |
| 2 | 到期回忆、换个人信息 | 不先看答案是否想起；准确性单列 |
| 3 | 手机练一次并中断 | 已做是否保存，未做不算失败 |
| 4 | 同聊再练，批量回传 | 失败不丢失，重复不增，时序正确 |
| 5 | 同目标新情境与未预演追问 | 跨天迁移机会、完成/未完成/未知 |
| 6 | 用户提供短素材或自由交流 | 模仿和提取是否分开；任务负担 |
| 7 | 复查报告并选下一周重点 | 到期回忆率的分母、提示比例、迁移样本、愿不愿继续 |

每天结束补一个主观项：今天负担0–4、是否愿意明天继续。样本太少或情境变化时不下进步结论。不要为了成功率隐去失败，也不要把练习次数当能力增长。真实效果、手机可用性和用户反馈仍待验证。

## 维护

升级前导出备份，保留上一版源码与方法版本。数据库版本迁移必须先备份；未知高版本拒绝写入。更正追加修正记录并重放，不手工覆盖历史。恢复先校验备份，在隔离目录检查报告，再恢复目标。方法变更采用 [变更流程](references/maintenance.md)。

评测案例为虚构数据，行为回放用于检查一致性，不证明学习效果。评测目录在源码旁的 `spoken-english-workspace`，不包含在安装包。
