# 原文与模板补齐迭代

旧包在 skill-snapshot；新版运行包在相邻 concept-shurachang。测试材料位于本目录 evals/evals.json，不进入售卖包。

iteration-1 是同样3个输入的新旧对照：薄肌谄媚、独立事件、期限错配。每种配置由一个无历史上下文的 Codex 子代理完成3题，不同配置相互不读结果。不是每题全新代理；每题只有一次运行，不能据此估计稳定性或泛化胜率。机制材料两边相同，用来隔离写作方法差异；本轮不测试联网查证或真实安装触发。原定跨生物/社会学的完整验收不能由这轮替代。

检查分为可计数字数和编辑人工判断；张力、自然度及是否像创作者，需用户评阅。没有获得真实token统计，不能把输出字符数当token，也不能把缺失记为0消耗。最终状态应为待用户评阅，不能把自动通过当作用户认可。
