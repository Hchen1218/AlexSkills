# 验证协议

验证资产不属于商品包。日期：2026-09-08。

两路使用 inputs.json 的相同用户输入和简短来源资料，都是普通成年观众与两性短口播。基线不读取 Skill；实验路只读取独立复制的 Skill 包，不读取源仓库或本次对话。来源资料为本次实现时查询后的摘要，非逐字摘录；测试 Agent 应注明使用了给定资料，不假装联网。

先生成 AI 与经济学两条代表稿供用户评阅。其他测试的执行／复核状态单列，未得到用户反馈时，不把自动判断写成人工验收。

每条保留原始生成结果与后续修改，不能用作者重写后的稿子冒充独立测试原输出。候选与 followup 分步执行；followup 是固定测试输入，不是实际用户选稿。

判断维度：概念准确、故事因果、映射可逆、候选有结构差异、口播可用、修改保持原方向、来源诚实。失败项记录具体句子或行为；仅做定性烟雾测试，不用少量样本计算稳定成功率或声称优于基线。

迁移样本：经济学、生物学、社会学的具体概念均未作为正文案例写入 Skill。方法参考含通用关系结构提示，因此不是完全未知的结构迁移。

隔离是新会话和文件访问范围约定，不是操作系统级沙箱。必须通过工具记录检查未读源仓库；不能声称验证了所有 Agent 或 SkillPay 平台。
