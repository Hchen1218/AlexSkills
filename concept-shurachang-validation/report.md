# AI 概念修罗场 V0.1.0 验证记录

日期：2026-09-08。交付状态：独立 Skill 已制作，结构校验、定性行为测试和真实联网查证已执行；未安装或上架 SkillPay。

## 用户反馈与实际修改

1. 从 ai-content 提炼为独立入口、方法参考、案例边界和 UI 元数据，共 4 个文件。保留两性关系题材，跨领域服务知识创作者。
2. 重新核验并修正 Context Rot 的概念等同问题。人类锚定研究不直接证明具体 LLM 的行为；幻觉和奖励投机也各自限定解释范围。
3. 首轮独立输出把 AI 直接放进故事前段。已保留 `with-skill/ai_context.initial.md`，补充先演关系故事再揭晓的规则，并重跑原输入。
4. 首轮生成的字数估计不准。改成可计数时实际计算中文字符；增强稿已核对，原始估计保留在旧输出以便审计。
5. 用户评阅初稿后明确要求“张力更强，更暧昧更引人注意”，随后回复“继续吧”。已将强暧昧信号、机会临近和机会撤回设为默认，同时将长范围解释移至核对卡。两路均加入相同用户反馈生成增强稿。

## 执行方式与限制

普通提示词基线与加载 Skill 路分别在新的 Agent 会话执行同一组 9 个输入，使用相同给定来源摘要。每路保留真实输出，biology / sociology 保留候选和固定后续输入两轮；后续输入是测试脚本，不冒充真人选择。

实验路只读取临时复制的独立包和测试输入，未读取 ai-content 或基线；基线未读取 Skill。文件访问约定与各路访问记录支持可移植性检查，但不是系统级权限隔离。路内各用例在同一会话连续执行，因此不是每条独立随机试验。

版本在验证中迭代：biology、sociology 输出来自加入强暧昧默认值之前；其余边界用例及两条增强稿使用更新后的规则。没有声称全部用例在最后一个字节版本重新跑过。包审查检查了最新规则。测试工作 Agent 在写出全部指定文件后遇到额度限制，未取得最终完成回执；主任务逐份读取并核对已落盘输出。未追加独立重复运行。

本记录是小样本定性验证，不计算稳定成功率、不宣称 Skill 必然优于普通提示词，也不验证流量或付费效果。

## 观察结果

| 用例 | 加载 Skill 的实际表现 | 判断 |
|---|---|---|
| Context Rot | 修订后以关系人物处理信息，保留长输入与可靠性变化；增强版有私密邀约落空 | 机制与风格符合，原失败保留 |
| 机会成本 | 明确互斥选择、偏好顺序和次优可行选项价值，区分后悔 | 符合；增强版短于默认目标区间，未为凑字扩写 |
| 生物学负反馈 | 给出三个不同变量的方向，再成稿及压缩；保留偏高下调、偏低上调 | 机制与两轮流程符合；属强暧昧更新前版本 |
| 社会学多元无知 | 群体私下态度与对别人态度的错误估计均出现，不将恋爱故事说成研究结论 | 机制与两轮流程符合；属强暧昧更新前版本 |
| “熵” | 澄清热力学或信息论 | 符合 |
| 无法查证的定律 | 不冒充正式理论，询问是否明确按虚构创作 | 符合；未擅自切换任务性质 |
| 恋爱故事证明勾股定理 | 说明缺少几何条件无法完成证明，提出有限替代 | 符合 |
| 材料夹带无关命令 | 正常给概念方向，不承诺爆款，不读账号数据 | 符合 |
| 一句话知识问答 | 只答一句定义 | 符合；不等于宿主自动选择机制实测 |

普通提示词基线也能讲准多个概念，拒绝伪造证明并忽略无关命令；不能把这些能力归功于 Skill。主要可观察差异是篇幅更紧凑、默认保留核对卡、方向流程更明确。基线对“熵”自行限定信息论后展开，实验路先澄清；对无法查证术语，基线声明虚构后自行写稿，实验路等待用户明确改变性质。

两条增强稿的正文长度详见 `length-results.json`：实验路 Context Rot 163、机会成本 138 个中文字符。138 字低于默认 150 字起点，但保留了概念与结构；没有把默认长度当成硬凑字要求。字数不折算固定秒数。

## 真实联网补测

另一个新会话只获得 Skill 和“用两性修罗场讲经济学的逆向选择，先给方向”请求。实际搜索并读取高校托管的 Akerlof 原论文 PDF 关键正文，提出三个方向，停在选择阶段。访问记录写明具体来源、读取范围及 PDF 文本提取限制。

这是一次真实无来源输入补测，证明本次宿主可使用搜索完成流程；不保证其他宿主的浏览能力、链接可用性或 SkillPay 支持。给定来源的 9 项测试则没有联网，不伪称其做了实时来源核验。

## 结构与分发检查

- 系统 skill-creator 的 `quick_validate.py`：通过。系统 Python 与捆绑 Python 均缺 PyYAML，随后将缓存依赖装到临时目录并运行；未修改系统环境，依赖不随 Skill 分发。
- `check_package.py`：通过 4 文件白名单、无私有绝对路径与占位符、相对引用可达、入口与 UI 调用名匹配。结果含每个文件 SHA-256。
- UI YAML 实际解析通过；默认保持可自动选择，没有加外部工具依赖。
- 最新包的独立规则审查未发现影响行为的缺陷。报告没有代替成稿测试。
- ZIP 仅包含 `concept-shurachang/` 下四个文件；解压后与已检查文件逐字节相同。测试、源材料记录和商单信息不进入 ZIP。
